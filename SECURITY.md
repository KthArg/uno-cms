# Seguridad

El procedimiento de reporte y el modelo de amenazas viven en
[`docs/SECURITY.md`](docs/SECURITY.md).

**Resumen: no abras un issue público.** Usa el aviso de seguridad privado de GitHub:
<https://github.com/KthArg/uno-cms/security/advisories/new>

Este fichero existe en la raíz porque es donde GitHub lo busca para enseñar el enlace de
"Report a vulnerability" en la interfaz del repositorio.

**Si estás leyendo esto en un fork**, la URL de arriba apunta al repositorio original, no
al tuyo: GitHub no la reescribe al copiar el fichero. Los fallos de **tu** despliegue van a
**tu** repositorio. Está explicado en [`docs/SECURITY.md`](docs/SECURITY.md).
