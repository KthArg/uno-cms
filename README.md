# UnoCMS

CMS acoplado 1:1 a una landing page, auto-hospedable en Vercel.
Un despliegue = una landing = un CMS.

El modelo de contenido se define en código (`cms.config.ts`); el CMS genera el panel
de administración, la validación, el versionado y la vista previa en vivo.
